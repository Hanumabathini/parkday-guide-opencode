A guide is only as useful as its weakest fact. That is why verification is the centre of the work on Parkday Guide rather than a final polish applied at the end. This post explains what happens between finding a detail and publishing it, and how you can read the result.

## One source rule

We start with primary sources. For park information the reference is NPS.gov. For reservations and booking details the reference is Recreation.gov. We do not take facts from other guides and we do not reuse their wording. If a detail cannot be found in a primary source, it does not go onto the page as a statement of fact. Sometimes that means a page says less than you might expect. That is deliberate.

## The retrieval date

When we confirm a statement, we record the day we retrieved it. That date is printed with the fact. It tells you how old the check is, which matters more than it sounds. A rule or an availability note can change while a page stays otherwise correct. The retrieval date gives you a starting point for deciding whether to check again. We keep the date visible so you never have to guess how fresh a detail is.

## Labels in plain language

You will see a small set of labels on pages and facts. Verified means we checked the statement against a primary source and recorded the retrieval date. Pending verification means the draft is in place but the check is unfinished, so treat the detail as provisional. Needs recheck means the recorded date is old enough that we want to confirm the statement again. These labels describe the state of our work, not the quality of the park or the value of the page.

## Rechecking and corrections

Rechecking is a repeat of the original process. We open the current source, find the same statement, and compare it with what we published. If it still holds, we update the retrieval date. If it has changed, we rewrite the text to match the source. Corrections from readers follow the same path. Send the page, the exact sentence, and the source you think is right. We do not change a fact until the primary source supports the change.

Because this is a pre-launch build, some statements still carry a pending verification label while a source check is finished. The 64 Parks Planning Checklist and the site pages use the same rules. When you use either one, the retrieval date and label are there to help you decide what to confirm yourself before you travel.
